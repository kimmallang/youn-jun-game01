Game01 asset layout

The game consists of index.html and the assets folder. Keep them together; the HTML loads graphics from relative paths inside assets.

On iPad, copy the complete game01 folder to the Files app (for example, On My iPad or iCloud Drive), then open index.html from that folder. Do not transfer index.html by itself because the graphics are separate files. Once copied, the game assets are stored locally and do not require an internet connection.

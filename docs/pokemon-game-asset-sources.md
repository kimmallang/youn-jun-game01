# 포켓몬 게임 에셋 및 데이터 참고처

포켓몬 관련 기능이나 화면을 만들 때 참고할 저장소를 용도별로 정리한다. 아래 설명은 프로젝트 작업 중 전달받은 참고 정보이며, 에셋을 실제로 반입하기 전에는 각 저장소의 최신 구성과 라이선스·이용 조건을 확인한다.

| 출처 | 제공 내용 | 이 프로젝트에서 참고할 때 |
| --- | --- | --- |
| [PokeAPI/sprites](https://github.com/PokeAPI/sprites) | 포켓몬 이미지 모음. 세대별 게임 스프라이트, 정면·뒷면, 색이 다른 모습, 공식 일러스트, 아이콘, Showdown 배틀 애니메이션 등을 제공한다. 아이템과 타입 이미지도 포함한다. 맵 타일이나 배경 모음은 아니다. | 배틀 포켓몬 이미지, 포켓몬 아이콘, 몬스터볼 등 아이템 이미지 |
| [PokeAPI/pokeapi](https://github.com/PokeAPI/pokeapi) | 이미지 저장소가 아니다. 포켓몬·종족·폼, 능력치, 타입, 기술, 특성, 아이템, 진화, 게임 등장 장소 등의 구조화된 정보를 제공하는 API와 데이터다. | 포켓몬 능력치·기술·타입 정보를 게임 로직에 연결하거나 데이터 갱신 |
| [teobz/pkmn-hgss-animated-overworld-sprites](https://github.com/teobz/pkmn-hgss-animated-overworld-sprites) | 하트골드·소울실버 스타일의 필드용 포켓몬 걷기 스프라이트. 1~493번 포켓몬의 상·하·좌·우 4방향, 4프레임 애니메이션을 GIF/APNG로 제공하며 색상·성별·폼 변형도 일부 포함한다. | 맵 위에서 플레이어를 따라다니는 포켓몬의 필드 애니메이션 후보 |

## 선택 기준

- 배틀 화면과 파티 아이콘은 `PokeAPI/sprites`를 먼저 살펴본다.
- 포켓몬의 수치와 기술 정보는 이미지와 분리해 `PokeAPI/pokeapi`에서 찾는다.
- 필드에서 걷는 동료 포켓몬은 `teobz/pkmn-hgss-animated-overworld-sprites`를 살펴보고, 현재 게임의 프레임 크기·팔레트·투명도와 맞는지 먼저 확인한다.
- 맵 배경과 타일은 위 저장소들을 맵 에셋 출처로 간주하지 않는다. 맵 작업은 프로젝트에 이미 있는 배경과 타일 규격을 우선 확인한다.
- 파일을 프로젝트에 복사하거나 API를 연결하기 전에 해당 출처의 라이선스, 저작권 표기 요구사항, API 이용 조건을 확인한다.
